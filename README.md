# Классификация тональности твитов о COVID-19

Проект классифицирует англоязычные твиты по пяти уровням тональности: от крайне негативной до крайне позитивной. Для решения используется двунаправленная LSTM с механизмом внимания.

## Что сделано

- автоматическая загрузка набора данных;
- очистка текста, обработка ссылок, упоминаний и хештегов;
- исследование баланса классов и длины текстов;
- построение словаря только по обучающей части данных;
- обучение BiLSTM с маскированным механизмом внимания;
- выбор лучшей эпохи по `macro F1` на валидационной выборке;
- итоговая оценка на отдельной тестовой выборке;
- матрица ошибок и таблица неверных предсказаний.

## Результаты

В исходном эксперименте были получены:

- accuracy: **0.805**;
- macro F1: **0.8132**.

Это исторические значения. В исходном ноутбуке тестовая выборка проверялась после каждой эпохи, поэтому она частично использовалась для выбора модели. В текущей версии это исправлено: данные разделены на `train`, `validation` и `test`, а тест используется только для финальной оценки. Новые значения появятся после полного повторного обучения.

## Запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter lab
```

Откройте `covid_tweet_sentiment_lstm.ipynb` и выполните ячейки по порядку. Данные скачаются автоматически. Лучшая модель и итоговые метрики сохранятся в `artifacts/`.

### Обучение на GPU

Ноутбук автоматически выберет CUDA, если она доступна в PyTorch. Строка `device: cuda` означает, что используется видеокарта. Если показано `device: cpu`, установите сборку PyTorch с поддержкой CUDA по инструкции на [официальном сайте PyTorch](https://pytorch.org/get-started/locally/), затем перезапустите kernel Jupyter.
